# Remote Mouse — Android

Клиент для телефона. Управляет компьютером с Windows в той же локальной сети: курсор, текст, громкость, воспроизведение и свои сочетания клавиш.

Нужен запущенный сервер [Remote Mouse](https://github.com/H1lp0p/RemoteMouse-desktop) на компьютере. Телефон говорит с ним только по протоколу версии 2.

## Что умеет

- Ищет компьютер в сети, подключается по QR-коду или по 6-значному коду с экрана ПК.
- Сохранённый компьютер открывается без кода.
- Режимы: мышь, стик, плеер, текст, панель из четырёх кнопок.
- Свои действия — последовательности клавиш для конкретного компьютера. 
- Настройки хранятся отдельно для каждого ПК.

## Как пользоваться

1. Компьютер и телефон должны быть в одной сети, сервер запущен, в его окне открыто подключение.
2. На телефоне выберите найденный компьютер, сохранённый или отсканируйте QR.
3. Для нового компьютера введите код с экрана ПК (или отсканируйте QR-код).
4. На экране управления переключайте режим. Мышь и стик двигают курсор, плеер — воспроизведение и громкость, текст пишет в поле, которое сейчас в фокусе, панель запускает назначенные действия.

Если компьютер виден в сети, но соединение не встаёт, проверьте, что точка доступа не изолирует клиентов и что на ПК открыты порты 12345 и 12346.

## Сборка

Нужны JDK 17 и Android SDK. Минимальная версия Android — 8.0 (API 28).

Из корня проекта:

```bat
gradlew.bat assembleDebug
```

Готовый apk: `app/build/outputs/apk/debug/app-debug.apk`.

В Android Studio достаточно открыть папку проекта и запустить конфигурацию `app`.
